# SIH pitch deck outline

1. **Title:** NE-Route AI — Intelligent Logistics & Accessibility Command Center for North East India.
2. **Problem:** fragmented incident reporting, uncertain route access and essential cargo delays across difficult terrain.
3. **Users:** government officials, logistics managers, field officers and public reporters.
4. **Solution:** one geospatial workflow connecting observe → predict → optimize → coordinate.
5. **Architecture:** React / Leaflet, FastAPI, PostgreSQL / PostGIS, ML microservice and graph routing.
6. **AI:** synthetic-data Random Forest risk prototype with feature-driver explanations; roadmap to validated event data and image classifier.
7. **Operations:** disruption-to-reroute flow, critical shipment exposure, multi-stop relief mission and response playbooks.
8. **Impact measurement:** time to verify incident, time to identify safe alternatives, critical cargo at-risk time, response acknowledgement and district access coverage. Report measured values only after a pilot.
9. **Governance:** source attribution, confidence / stale-data labels, RBAC, human verification, auditability and no autonomous dispatch.
10. **Scale:** integrate authorized GIS / road data, weather providers, state control rooms, SMS channels and offline maps.
11. **Roadmap:** validate baseline data, pilot corridors, expand districts, add satellite / CV and production resilience.
